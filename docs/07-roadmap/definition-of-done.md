# Definition of Done

A feature is done only when:
- Acceptance criteria pass.
- Typecheck/lint/build pass.
- Relevant unit, integration, API, and E2E tests pass.
- Authorization and data exposure are reviewed.
- Rate limiting/idempotency are addressed where applicable.
- Observability exists for important operations.
- Documentation is updated.
- Migration/rollback impact is understood.
- No secrets or sensitive data are committed.
