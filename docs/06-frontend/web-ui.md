# Web UI

The web application is the reference client for the shared myStay backend.

## Implemented screens

- Marketplace landing/search
- Listing discovery and listing detail
- Provider dashboard
- Provider listings and listing editor
- Provider properties and property creation
- Provider inquiry management
- Provider inventory availability
- Authentication entry screen
- Notifications

The UI is intentionally backed by the versioned API boundary so a future mobile client can reuse the same application/domain contracts.
