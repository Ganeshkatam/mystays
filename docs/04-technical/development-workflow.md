# Development Workflow

1. Update product specification.
2. Record significant architectural choices as ADRs.
3. Create a focused implementation issue.
4. Implement with tests.
5. Update documentation.
6. Run typecheck, lint, tests, security checks, and build.
7. Review authorization and data exposure.
8. Merge through protected-branch review.

## Definition of Done
- Acceptance criteria satisfied.
- Important boundaries tested.
- Security reviewed.
- Observability included where needed.
- Documentation updated.
- No secrets or sensitive data committed.
