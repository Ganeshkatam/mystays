# Domain Model

Core entities: User, Profile, Provider, Property, Building, Unit, Room, Bed, Listing, ListingMedia, Amenity, Location, Availability, Favorite, SavedSearch, Inquiry, Conversation, Message, Viewing, Application, Verification, Review, Booking, Payment, Agreement, Tenancy, MaintenanceRequest, Notification, Report, AuditEvent.

Physical property and market listing are separate concepts. Availability is authoritative for allocatable inventory.
