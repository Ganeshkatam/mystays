# Product Principles

- **Trust is a feature:** verification, freshness, moderation, and transparent pricing are core.
- **Search is a product:** relevance and location quality matter more than feature volume.
- **Availability is first-class:** stale inventory damages marketplace trust.
- **Domain clarity:** property, listing, availability, identity, and transactions have explicit boundaries.
- **Progressive complexity:** start simple while preserving clean paths to future capabilities.
- **User control:** preferences, privacy, notifications, and data handling are explicit.
