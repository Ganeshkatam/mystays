# Long-Term Vision

myStay can evolve from accommodation discovery into a housing lifecycle platform:

Discover → Compare → Contact → Visit → Apply → Verify → Secure → Move In → Pay → Maintain → Renew/Move Out

Expansion areas:
- Roommate matching
- Booking and applications
- Payments and agreements
- Resident services
- PG/co-living operations
- Corporate and student housing
- Provider SaaS
- Partner APIs
