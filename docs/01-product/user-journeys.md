# User Journeys

## Seeker
Onboard → Set preferences → Search → Filter → Inspect listing → Shortlist → Inquire → View → Apply → Verify → Secure → Move in.

## Provider
Onboard → Verify → Add property → Add inventory → Create listing → Publish → Receive leads → Manage visits/applications → Manage occupancy.

## Resident
Move in → View agreement → Pay → Raise maintenance requests → Renew or move out.

## Admin
Monitor → Review → Moderate → Resolve → Audit → Analyze.
