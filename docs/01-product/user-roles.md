# User Roles

| Role | Core responsibility |
|---|---|
| Seeker | Discover and secure accommodation |
| Provider | Supply and manage accommodation |
| Resident | Manage an active stay |
| Property Manager | Operate properties for owners |
| Staff | Perform operational services |
| Admin | Trust, moderation, support, and operations |
| Partner | Integrate with myStay |

Authorization must be capability-based and enforced server-side.
